# I+D · Cuaderno de cocina

App personal para crear platos: sabores que dominan, ficha técnica, importar recetas, libreta de pruebas y radar de tendencias.

- Abrir en el móvil: la dirección de GitHub Pages de este proyecto. En el navegador, «Añadir a pantalla de inicio».
- Los platos se guardan solo en cada dispositivo (en el navegador). Nada de lo que apuntas se sube aquí.
- Para pasar platos entre el PC y el móvil: menú → descargar copia de seguridad en uno y recuperarla en el otro.
- `fuente/` tiene el código; `index.html`, `radar.js`, `sw.js` y los iconos son la app publicada.
